Industry Verification Website

a website redesign project for PT Surveyor Indonesia (Persero) aimed at enhancing the user experience and visual appeal of their industry verification services. The redesign focused on creating a modern, intuitive interface that simplifies navigation and improves accessibility for users seeking verification services. Key features included website to be more dynamic than before. the implementation makes navigation to certain pages more easier and faster.

Background

PT Surveyor Indonesia’s industry verification website currently relies on a static design to provide information about the company's services. This static site suffers from several shortcomings, including unclear information categorization, non-functional features that prevent users from retrieving relevant information, an unappealing layout, and other issues. Consequently, improvements are needed to ensure the site delivers better information and allows users to easily access the data they require. Therefore, a decision has been made to rebuild the PT Surveyor Indonesia industry verification website to enhance its overall quality and performance.

Problem Statement

  1. The website's visual appeal is lacking, and it provides minimal information for users.
  2. The website layout is poorly organized.
  3. Certain functions, such as the search feature, do not work properly.
  4. The website is not dynamic, making it difficult to add new information.

Pre-redesign view

Several points regarding the initial website design emerged during discussions with stakeholders:
1. The industry verification website was merely a single-page site displaying descriptions of PT. Surveyor Indonesia's services; it provided no information other than the services listed on that page.
2. The layout of the website's components was poorly organized, resulting in an unappealing visual presentation.
3. The company required a website capable of displaying the latest corporate information and updates regarding the services provided.
4. The website's search function was ineffective; it failed to locate the information users were seeking.
5. The company wanted the website to provide accessible contact information for users.
